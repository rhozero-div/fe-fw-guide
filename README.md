# 火焰纹章：万缕千丝 — 第一部速查手册

> 《Fire Emblem: Fortune's Weave》第一部（四条主角线各 12 章）全数据速查工具：角色成长、挖角条件、稀有物品、外传时点、熟练度习得技能。
>
> **🌐 在线使用：<https://rhozero-div.github.io/fe-fw-guide/>**
>
> 手机、平板直接打开即可，无需安装；也可下载 `index.html` 双击离线使用。

---

| 模块 | 数据量 | 说明 |
|---|---|---|
| ① 角色成长图鉴 | **63 名**角色 | 个人特技、血印、9 项成长率（热力着色）、擅长熟练度、初始职业/阵营、四路线加入时点、官方立绘头像 |
| ② 第一部挖角 | **151 条**记录 | 凯伊 36 / 迪托利希 39 / 赛奥朵拉 39 / 蕾达 37，含支援等级、名声要求、特殊素材与支线条件、最早时点 |

| ④ 外传一览 | **9 个**外传 | 触发角色、章节与日历日期窗口、可用路线矩阵、奖励、对第三部的影响 |
| ⑤ 熟练度习得技能 | **117 项**特技 + **355 个**战技 | 按 13 个熟练度系统分等级（E→S+）整理，支持按角色反查 |

## 功能

- **路线联动**：顶部切换主角线后，五个模块全部按该线过滤/高亮
- **排序与搜索**：角色表任意列排序（默认按 9 项成长合计降序），全局搜索当前模块
- **角色反查**：点开角色详情卡，可直接跳到该角色能学会的熟练度特技与战技清单
- **单文件离线**：头像已内嵌为 base64，断网可用

## 项目结构

```
.
├── index.html                               # 构建产物（GitHub Pages 入口）
├── 火焰纹章-万缕千丝-第一部速查手册.html      # 同一份产物（中文文件名，便于本地保存）
├── build/
│   ├── template.html                        # 页面模板，含 __DATA__ 占位符与全部前端逻辑
│   └── build.py                             # 注入数据 → 生成上述两个 HTML
└── data/                                    # 数据源（唯一真相来源）
    ├── characters.json                      # 63 名角色：特技/血印/成长率/熟练度/加入时点
    ├── recruitment.json                     # 151 条挖角记录
    ├── items.json                           # 转职票证、稀有武器、稀有技能、关键物品
    ├── paralogues.json                      # 9 个外传
    ├── proficiency_skills.json              # 117 项熟练度习得特技 + 等级顺序
    ├── combat_arts.json                     # 355 个战技及可习得角色
    └── portraits.json                       # 63 名角色头像（base64）
```

## 更新数据

所有内容由 `data/*.json` 驱动，改完数据重新构建即可：

```bash
python3 build/build.py     # 需要 Python 3.8+，无第三方依赖
```

该命令会重新生成 `index.html` 与中文名 HTML。推送到 `main` 分支后，GitHub Pages 约 1 分钟内自动更新。
